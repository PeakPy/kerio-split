# Branding

| File | Use |
| --- | --- |
| `logo/app-icon-original.jpg` | Locked master (logo C) |
| `logo/app-icon-1024.png` | Cleaned plate for icons |
| `logo/app-mark.png` | Transparent mark |
| `logo/app-mark-template.png` | Menu bar template |
| `banner-hero.png` | README header |
| `banner-features.png` | Optional feature strip |
| `social-card.png` | Social preview |

Sync into the macOS app with `scripts/sync-branding.sh` (also run by `make build`).
