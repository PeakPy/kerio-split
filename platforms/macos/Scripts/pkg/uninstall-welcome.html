Uninstall Kerio Split

This package removes Kerio Split from this Mac. It does not install the app.

About the Install button: macOS Installer always labels the final button “Install”, even for uninstall packages. Clicking it will uninstall Kerio Split — it will not put the app back.

What gets removed:

  • Kerio Split.app in Applications
  • Route helper and sudoers entry
  • Kerio Split settings under Application Support

You will be asked for an administrator password.
